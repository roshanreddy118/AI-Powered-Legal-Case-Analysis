# LegalAI - Indian Judiciary Case Analysis System

An AI-powered legal case analysis platform designed specifically for the Indian judiciary system. This application helps identify potential wrongful convictions, prosecutorial misconduct, and bias patterns using advanced AI analysis powered by Google's Gemini API.

## 🌟 Features

- **Wrongful Conviction Detection**: Analyze cases for potential wrongful conviction indicators
- **Prosecutorial Misconduct Analysis**: Identify patterns of prosecutorial misconduct
- **Case Similarity Analysis**: Compare with similar cases across jurisdictions
- **Bias Detection**: Detect demographic and systemic bias patterns
- **Brilliant UI**: Stunning glassmorphism design with glowing effects and animations
- **Real-time Analysis**: Powered by Gemini AI for instant insights

## 🚀 Tech Stack

- **Frontend**: Next.js 16.2.4 with TypeScript
- **Styling**: Tailwind CSS with custom animations and glowing effects
- **AI**: Google Gemini API integration
- **Icons**: Lucide React
- **Deployment**: Vercel-ready configuration

## 🛠️ Development

### Prerequisites
- Node.js 18+ 
- npm or yarn
- Gemini API key from Google AI Studio

### Installation

1. Clone the repository
```bash
git clone <repository-url>
cd legal-ai-analysis
```

2. Install dependencies
```bash
npm install
```

3. Set up environment variables
```bash
cp .env.example .env.local
```

Add your Gemini API key and other required variables to `.env.local`

4. Run the development server
```bash
npm run dev
```

5. Open [http://localhost:3000](http://localhost:3000) to view the application

## 🌐 Deployment

This project is configured for Vercel deployment:

1. Push to your Git repository
2. Connect to Vercel
3. Set environment variables in Vercel dashboard
4. Deploy
